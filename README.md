# Game Library

A self-hosted web application for managing a personal game library.

## Features

- User login
- Game management
- Nested folders
- Games can be organized into folders
- Tile and list views
- Game search, filtering and sorting
- Game status tracking
- Rating, genre and description
- Special visual state for completed/platinized games
- Local JSON-based data storage
- Self-hosted deployment

## Game statuses

- Ongoing
- Done
- Paused
- Dropped
- To Be Played
- Platinized

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- TanStack Query
- Zod
- Lucide React

### Backend

- Node.js
- Fastify
- TypeScript
- Zod

### Storage

The application will use local JSON files instead of a traditional database.

### Deployment

The application is designed to run on a personal/home server.
